# 内压薄壁封头屈曲载荷预测系统

## 📌 项目简介
本项目基于内压薄壁封头的复杂几何缺陷参数，构建了基于 XGBoost（极端梯度提升树）的屈曲载荷预测代理模型。旨在提供一种区别于传统非线性有限元分析（FEA）的快速评估工具。

模型输入包含 10 项几何与材料特征（经无量纲化处理），输出为屈曲载荷（MPa）。本仓库包含了模型训练代码（train）、数据预处理管道(datap)以及基于 Streamlit 开发的前端交互式 Web 应用。
基于保密考虑。本仓库不提供真实数据，仅提供训练用数据格式

## 🛠️ 核心功能模块
系统主要包含以下四个子页面：

1. **单次参数预测**：支持手动输入各项物理尺寸及缺陷幅值，实时输出预测的屈曲载荷。
2. **批量 Excel 预测**：支持上传特定格式的 Excel 数据文件，系统自动进行批量计算，并将结果追加至原表供下载。
3. **连续敏感性分析**：在设定的物理安全范围内，基于连续插值点绘制单变量对屈曲载荷的影响曲线。
4. **真实离散敏感性分析**：严格基于模型训练集的真实无量纲样本空间进行取点，客观呈现决策树类模型固有的分段常数（阶梯状）响应特性，不进行虚假的数学平滑。

## 🛡️ 安全约束机制
为防止机器学习模型在未知数据上产生不可靠的外推（Out-of-Distribution），系统底层内置了**特征边界校验模块**。当用户输入的物理参数经无量纲转换后，超出了模型在训练集中学习到的特征极值域，系统将阻断预测并给出警告，保障工程评估的边界安全。
